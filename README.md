# Atajo al teórico DGT

App de estudio para el examen teórico del permiso B (España) con repaso espaciado, simulacros 30/3, chuleta de cifras y preguntas con imagen. Normativa a 26/11/2026, incluida la reforma del Reglamento General de Circulación (RD 518/2026, en vigor desde el 1/10/2026).

- Funciona sin servidor: un solo `index.html` publicado con GitHub Pages.
- El progreso se guarda en el navegador (localStorage) y se puede exportar como código desde «Mis fallos».
- Instalable en el móvil («Añadir a pantalla de inicio») y usable sin conexión.

Preguntas de redacción propia; no sustituyen al material oficial.
